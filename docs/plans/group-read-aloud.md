# グループの単語をすべて読み上げる

## 目的・背景

グループの単語を、画面を操作せずに耳で聞き流せるようにしたい（2026-11-04）。
今の読み上げ（`SpeechService`）は、提示カード・回答後カード・リスニングクイズで 1 語ずつ鳴らすだけで、続けて読む手段が無い。

グループ詳細から、グループの単語を順に読み上げる「読み上げ」モードを足す。最後まで読んだら頭から繰り返す「ループ再生」もできるようにする。

## 決めたこと（2026-11-04）

1. **1 語で読むもの**: 単語（英語）→ 意味（日本語）→ 例文（英語）→ 例文の和訳（日本語）
   - 意味が複数あるマイ単語は、単語を 1 回読んだあと、意味ごとに「意味 → 例文 → 例文の和訳」を読む（こちらで決めた）
   - 例文・和訳が空なら飛ばす。穴埋めの文章（端末にためたもの）は使わない（こちらで決めた）
2. **画面を消しても鳴らし続ける**: バックグラウンドオーディオ（`UIBackgroundModes: audio`）を入れ、
   ロック画面・コントロールセンターに今の単語と再生・一時停止・前後を出す（`MPNowPlayingInfoCenter`・`MPRemoteCommandCenter`）
3. **並び順**: グループの並びのまま（シャッフルしない）
4. **ほかのアプリの音**: 止める（読み上げ中は `.duckOthers`・`.mixWithOthers` を付けない）。
   終わったら `.notifyOthersOnDeactivation` でほかのアプリに戻す
5. **速さ**: 固定。今の速さ（英語の単語 0.42・文 0.45）にそろえ、日本語の速さは実機で聞いて決める
6. **学習の記録**: 残さない（進捗・回答ログとも。ドリルと同じ）

## 対応方針

### 画面

- グループ詳細の学習カードの「穴埋め」の下に「読み上げ（全 N 語）」（アイコン `speaker.wave.2`）。単語が無ければ押せない
- 読み上げ画面（フルスクリーン）
  - 今読んでいる語を大きく出す（単語・意味・例文。読んでいる部分を強調）。「N / M 語」と、ループなら何周目か
  - 操作: 再生 / 一時停止、前の語・次の語、ループのオン・オフ、閉じる
  - 一覧から語を押すと、そこから読む
- 閉じたら読み上げを止める

### 読み上げの仕組み

- `ReadAloudPlayer`（`@Observable`）: 読み上げる項目の並び（1 語 = 英語・日本語の文の並び）・今の位置・再生中かどうか・ループを持つ。
  1 語を読み終えたら次へ、最後まで読んだらループなら頭へ、そうでなければ止まる
- 実際に声を出す部分は小さなプロトコル（「この文の並びを読んで、終わったら知らせる」「止める」）にして、テストでは偽物に差し替える
- `SpeechService` は 1 回の読み上げのたびに `AVSpeechSynthesizer` を作り直している（素早く止めると詰まる対策）。
  読み終わりを知る必要があるので、`SpeechService` に「読み終えたら呼ぶ」完了通知を足すか、読み上げ専用の実装を分けるかは Phase 1 で決める。
  どちらにしても、読み上げ中に提示カードなどの読み上げが割り込まないよう、片方が始まったら片方を止める
- 日本語（意味・例文の和訳）は日本語の声（`ja-JP`）で読む（端末に無ければ日本語の部分は飛ばす）
- 音声セッション: 読み上げ中だけ、ほかのアプリを止めるカテゴリ（`.playback`・`.spokenAudio`、オプション無し）にする。
  学習中の読み上げ・効果音は今までどおり `.duckOthers`（`LearningAudioSession` に、どちらで有効にするかを渡せるようにする）
- 通話・ほかのアプリの再生で音声セッションが止められたら一時停止にする（`AVAudioSession.interruptionNotification`）

## Phase

### Phase 0: 何を読むか・どこまで鳴らすかを決める

### Phase 1: 読み上げの仕組み（`ReadAloudPlayer`）

- 読み上げる項目の組み立て（決めた内容で、語 → 文の並び）、再生・一時停止・前後・ループ、割り込みでの一時停止
- Swift Testing（偽の声で）

実装メモ（2026-11-04）:

- `ReadAloudScript`（`Core/ReadAloud.swift`）: 語 → 文（`ReadAloudLine`）の並び。日本語は声に出す文だけ整える
  （「／」→「、」、「〜」は消す、「［で］」のような言い換えは読まない。画面の文はそのまま）
- `ReadAloudPlayer`: 声の部分はプロトコル `ReadAloudSpeaking`（`speak(lines, onLineStart, onFinish)`・`stop`・`finish`・`onInterruption`）。
  前の `speak` の知らせは番号（generation）で無視する。前後の語へは再生中ならそこから読み、止まっていれば位置だけ動かす。
  最後の語の「次へ」はループなら頭へ（周回 +1）。読み終えて止まったら `finish` でほかのアプリの音を戻す
- 声は `SpeechService` を広げず、読み上げ専用の `ReadAloudSpeechEngine` に分けた（読み終わりの知らせ・日本語の声・カテゴリが違うため）。
  読み始めるときに `SpeechService` を止める。読み終えて次の語へ進むときは `AVSpeechSynthesizer` を使い回し、途中で止めたら作り直す
- `LearningAudioSession` は `activate(for: .learning / .readAloud)`。読み上げ中は学習側からの無効化・カテゴリの変更を無視する
  （`SpeechService.stop()` の遅れた無効化で読み上げが止まらないように）
- 割り込みに加えて、イヤホンが抜けたとき（`routeChangeNotification` の `.oldDeviceUnavailable`）も一時停止にした
- 速さ: 英語の単語 0.42・文 0.45、日本語は仮に 0.5。文の間 0.25 秒・語の間 0.8 秒
