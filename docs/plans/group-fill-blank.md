# グループで穴埋めモードを試せるようにする

## 目的・背景

「文章の空欄に合う単語を選択肢から選ぶ」出題を増やしたい（2026-11-03）。
穴埋め（`QuizType.fillBlank`）はすでにあるが、出題形式はステージで決まり、穴埋めになるのはステージ 3 の語だけ。
ドリルも同じ決め方なので、ほとんど目にしない。

まずは「とりあえず試せる」ことを優先し、グループ詳細に既存のドリルとは別のボタンで「穴埋め」モードを足す。
ステージの割り当ての見直しや、いつもの学習への組み込みは、試してから決める。

## 対応方針

- **ドリルの一種として作る**: 進捗・回答ログを残さない。流れは「全語クイズ → 間違えた語の再出題 → 締め」でドリルと同じ。
  違いは形式を穴埋めに固定することだけ
- `SessionRunner(drillWordIds:quizType:)`: 形式を固定できるようにする（省略時は今のドリルと同じくステージで決める）。
  再出題も同じ形式で出す
- 出題する語: 例文に見出し語が見つかって空欄にできる語だけ（`QuizBuilder.canFillBlank`）。
  意味が複数ある語は、どれかの意味で空欄にできればよい（どの意味で出すかは今の穴埋めと同じく `QuizBuilder` が選ぶ）
- グループ詳細: 「ドリル」の下に「穴埋め（N 語）」ボタン。並びはシャッフル。
  空欄にできない語があるときは「例文に単語が見つからない M 語は出ません」と添える。N が 0 なら押せない
- 画面: 問題カードの見出しは今のドリルと同じ「ドリル」、右上の形式は「穴埋め」。締めはドリルと同じ
- DebugSeed `group-fill-blank`（グループ詳細から穴埋めを開く）を足す

## 影響範囲

- iOS: `Features/Session/SessionRunner.swift`・`SessionView.swift`、`Features/Groups/GroupDetailView.swift`、
  `Core/QuizBuilder.swift`（`canFillBlank`）、`App/DebugSeed.swift`
- サーバー・同期・データには影響しない（ドリルなので何も保存しない）

## テスト方針

- Swift Testing
  - 形式を穴埋めに固定したドリルは、すべての問題（再出題を含む）が穴埋めになり、進捗・ログを残さない
  - 形式を指定しないドリルは今までどおり
  - `canFillBlank`: 例文に見出し語がある語・ない語、意味が複数ある語で 2 つ目の意味だけ空欄にできる語
- 既存テストがすべて通る・SwiftLint 警告 0
- シミュレータで、グループ詳細のボタンと穴埋めの出題・締めを確認

## 結果（2026-11-03）

- `SessionRunner(drillWordIds:quizType:)` と `drillQuizType` を足し、固定した形式を再出題にも使う。`QuizBuilder.canFillBlank` を足した
- グループ詳細の「ドリル」の下に「穴埋め（N 語）」（アイコン `questionmark.square.dashed`）。空欄にできない語の数を下に添える
- DebugSeed `group-fill-blank`
- Swift Testing 205 件成功・SwiftLint 警告 0。シミュレータで、デモのグループ（13 語中 12 語が穴埋めにできる）のボタンと、
  穴埋めの出題（「He ＿＿＿＿ every morning.」に take a shower など 4 択）を確認
- 気づいたこと（今回は直していない）: 空欄には活用した形（takes a shower）が入るが、選択肢は原形（take a shower）で出る。
  今の穴埋めからある振る舞い。試してみて気になるなら、選択肢を例文の形にそろえるかを別に考える
