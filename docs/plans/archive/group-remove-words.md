# グループから単語を分かりやすく外せるようにする（iOS）

作成日: 2026-11-03

## 目的・背景

- [word-add-single-screen](word-add-single-screen.md) で「単語を追加」から外す操作（チェックを外して「完了」）を無くした
- グループから語を外す手段は、グループ詳細の行の **スワイプ「外す」だけ** になり、気づきにくい。まとめて外す手段も無い
- 外しても語・進捗・自作語は消えない（`GroupEditor.remove(wordIds:from:)` はグループの中の ID を消すだけ）ので、確認ダイアログは出さない

## 対応方針

グループ詳細（`GroupDetailView`）に、見つけやすい外し方を 2 つ足す。スワイプは今のまま残す。

1. **行の長押しメニュー**に「グループから外す」（1 語だけ外したいとき）
2. **「⋯」メニューに「単語を選んで外す」**（まとめて外したいとき）
   - 押すと一覧が選択モードになる（行の左に丸いチェック。学習カードは隠す）
   - ツールバーは「完了」と、下に「外す（N）」（選んでいなければ押せない）と「すべて選択 / すべて解除」
   - 「外す（N）」で選んだ語をまとめて外し、選択モードを終える
   - 単語が無いときはメニューの項目を押せなくする

## Step

- Step 1: 長押しメニューと選択モードを実装する（`GroupDetailView`）
- Step 2: 画面確認用の `DebugSeed`（`group-select`: 選択モードで 2 語選んだ状態）を足し、シミュレータ・実機で確認する

## 結果（2026-11-03）

- 行の長押しメニュー「グループから外す」と、「⋯」→「単語を選んで外す」の選択モードを追加（スワイプはそのまま）
- 選択モードでは学習カード・戻るボタン・タブバーを隠す（下のツールバーの「すべて選択」「外す（N）」がタブバーに重なって押せなかったため）
- `WordGroupTests` にまとめて外すテストを追加。Swift Testing 184 件成功・SwiftLint 警告 0
- シミュレータで選択モード（`VOCAB_DEMO_SCREEN=group-select`）と通常の表示を確認。実機でも確認済み

## 影響範囲

- iOS: `Features/Groups/GroupDetailView.swift`、`App/DebugSeed.swift`
- データ・同期は今の「外す」と同じ（`GroupEditor.remove`。グループの `updatedAt` が進んで同期される）

## テスト方針

- まとめて外すのは既存の `GroupEditor.remove(wordIds:from:)` をそのまま使う。複数 ID を外す・順番が保たれるテストが無ければ `WordGroupTests` に足す
- 既存テストがすべて通る・SwiftLint 警告 0
- シミュレータ: 長押しで外す / 選択モードで 2 語外す / すべて選択 / 単語が 0 になったら空状態に戻る
