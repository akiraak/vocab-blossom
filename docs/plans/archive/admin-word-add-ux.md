# 管理画面の「単語を追加」を見やすく・分かりやすくする

## 目的・背景

単語の追加 Phase 2（`83ea8d8`）で、管理画面のグループ詳細の単語の追加を iPhone と同じ機能にそろえた。
しかし使ってみると「見づらいし分かりづらい」（2026-11-03）。ローカルで画面を見て、次の問題を確かめた。

1. 入口が遠い: 「単語を追加」がグループの単語一覧の下にあり、見出しも小さくほかの節と見分けがつかない
2. 結果が長く、ボタンが遠い: 「home」で 32 件。例文に home が出てくるだけの語（already・busy など）が理由の表示もなく混ざる。
   「選んだ単語を追加」は一番下（約 1,400px 下）で、選ぶまで薄い
3. 結果があっても、その下に長い作成フォーム（英語・意味・品詞・例文・訳と空の「意味を追加」の欄）がいつも出ている
4. 単語帳に無い語（commute）では、AI の候補カードと同じ内容を入れたフォームが二重に並び、「フォームに入れる」もあって何をすればよいか迷う
5. 説明の多くが小さい灰色の文字で、どこが大事か分からない

## 対応方針（2026-11-03 に決定: 置き場所は「ページ上部の枠」、範囲は「まとめて直す」）

機能・送る内容（POST の形）は変えず、見せ方だけを直す。

### Step 1: 「単語を追加」をページ上部の枠にする

- グループ名のすぐ下に、枠で囲んだ「単語を追加」を置く。検索欄を大きくし、単語一覧（単語・フレーズ）はその下にする
- 単語が 0 語のときの案内も「上の『単語を追加』で」に直す

### Step 2: 検索結果を短くし、追加ボタンを近くに

- `searchWords` の順位づけを `searchRank` として切り出し、例文だけで一致した語を分ける
- 英語・意味で一致した語を先に出し、例文に出てくるだけの語は「例文に「home」が出てくる語（N）」として `<details>` でたたむ
- 「選んだ N 語を追加」を結果の上にも置き、結果の欄の中でスクロールしても見えるよう上に固定（sticky）する
- 行のどこを押してもチェックが切り替わる（`label` を行全体に）

### Step 3: 作成フォームと AI の出し方を整理する

- 結果があるときは、作成フォームを `<details>`「一覧に無ければ「home」をマイ単語として作る」でたたむ
  （入力の誤りで出し直すとき・同じ綴りの案内があるときは開いておく）
- 結果が 0 件で AI が使えるとき: AI の候補カードを主役にする。単語帳に無い語のカードは
  「この内容で作って追加」（チェックした意味でフォームを埋めてそのまま送る）と「直してから作る」（フォームを埋めて開く）。
  「フォームに入れる」は無くす。フォームは最初はたたんでおき、AI が失敗したら開く
- 空の「意味を追加」の欄は最初から出さず、「＋ 意味を追加」ボタンで出す（マイ単語ページ・編集画面のフォームも同じ）
- 説明文を減らし、大事な案内は通常の文字にする

### Step 4: テストと確認

- Vitest: 例文だけの一致がたたまれる・作成フォームのたたみと開き・空の意味の欄が出ない（ボタンで出す）・既存の流れ
- ローカルでサーバーを起動し Chrome 拡張で確認: home（例文の語がたたまれ、選ぶと上で追加できる）/ commute（AI のカードから 1 回で作る・直してから作る）/
  beautifull（単語帳の beautiful を追加）/ マイ単語ページで意味を足す

## 影響範囲

- server: `src/admin/pages.ts`（グループ詳細・自作語のフォーム）、`src/http/html.ts`（CSS・JS）、
  `src/words/bundled.ts`（`searchRank` の切り出し）、`src/admin/routes.ts`（検索結果に一致の種類を付ける）、関連テスト
- iOS・同期・データには影響しない

## テスト方針

- Vitest（ルート・ページの HTML）と型チェック
- ローカルのサーバー + Chrome 拡張で画面を見る。反映は指示があってから g3plus へ

## 結果（2026-11-03）

- Step 1: グループ名の下に枠（上に色の線）で「単語を追加」。検索欄を大きくし、検索語が無ければフォーカス。単語一覧は「このグループの単語・フレーズ（N）」として下へ
- Step 2: `rankWords`（`searchWords` と同じ並びで順位も返す）を足し、例文だけの一致を `exampleOnly` に。
  「home」は 32 件 → 英語で一致した 6 件だけ表で出し、例文の 26 件は「例文に「home」が出てくる語（26 件）」でたたむ（例文だけのときは開く・一致した例文を見せる）。
  結果の上に「「home」の検索結果 N 件」と「選んだ N 語を追加」を sticky で置き、行のどこを押しても選べる・選んだ行は色付き
- Step 3: 結果があるときは作成欄を「一覧に無ければ「home」をマイ単語として作る」でたたむ（入力の誤り・案内で出し直したときは開く）。
  0 件で AI が使えるときはフォームを「自分で入力して作る」でたたみ、AI のカードに「この内容で作って追加」（フォームを埋めて送る）と
  「直してから作る」（埋めて開く）。「フォームに入れる」は無くした。AI が失敗・候補 0 件ならフォームを開く。
  空の「意味を追加」の欄は出さず「＋ 意味を追加」ボタンで足す（まだ使っていない品詞を選ぶ。マイ単語ページ・編集画面も同じ）。サーバー側の `nextSensePos` は使わなくなったので消した
- Step 4: Vitest 181 件成功・型チェック OK。ローカルで Chrome 拡張で確認: home（6 件 + たたみ、行を押して 2 語選び「選んだ 2 語を追加」で入る）/
  commute（自動で調べ、カード 1 枚・フォームはたたまれ、「直してから作る」で開く、「＋ 意味を追加」で意味 3（形容詞）、「この内容で作って追加」で動詞・名詞の 1 語・空の意味 3 は無視）/
  beautifull（単語帳の beautiful を案内）/ マイ単語ページのフォーム
