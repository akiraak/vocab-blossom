# 単語検索で、探している語を上に出す（iOS）

作成日: 2026-11-03

## 目的・背景

- 実機で「一度削除した単語が、検索しても出てこない」と報告があった（2026-11-03）
- iOS の検索（`WordStore.filter`）は、英語・意味・例文のどれかに検索語を含む語を **単語帳の順のまま** 返す。
  例文に検索語を含む語も同じ扱いなので、探している語が後ろに埋もれる
  - シミュレータで「home」を検索すると、home は 10 番目（already・anybody・because… が先に並ぶ）
  - グループから外した語は「単語を追加」で選べる状態に戻っているが、一覧の下のほうにあって見つけにくい
- サーバーの検索（`server/src/words/bundled.ts` の `searchWords`）は「英語の前方一致 → 英語の部分一致 → 意味の部分一致」の順に並べており、iOS だけ並びが無い

## 対応方針

- `WordStore.filter` の結果を、検索語との近さで並べ替える。同じ順位の中は今の並び（単語帳の順）のまま
  1. 英語が完全に一致（大小文字・前後の空白は無視）
  2. 英語が前方一致
  3. 英語が部分一致（熟語の途中の語など）
  4. 意味が部分一致
  5. 例文が部分一致
- 絞り込みの条件（英語・意味・例文の部分一致、大小文字無視）は変えない。空の検索語なら今と同じく全件・元の順
- `WordStore.filter` を使う単語一覧（`WordListView`）と「単語を追加」（`WordPickerView`）の両方に効く
- マイ単語ごと消した語は単語帳から無くなるので、検索に出ないのは仕様どおり（今回は変えない）

## 結果（2026-11-03）

- `WordStore.filter` を「完全一致 → 前方一致 → 英語の部分一致 → 意味 → 例文」の順に並べるようにした（同じ順位の中は元の並び）
- テスト 2 件を追加（同梱語の home が先頭 / 順位と元の並び・空の検索語）。Swift Testing 183 件成功・SwiftLint 警告 0
- シミュレータで「home」を検索し、home・hometown・homework… の順に出ることを確認（前は 10 番目）
- 実機で確認済み（2026-11-03）

## 影響範囲

- iOS: `Core/WordStore.swift`（`filter`）、テスト `WordStoreTests`
- サーバー・データ・同期には影響しない

  - 同じ順位の中は元の並び / 大小文字・前後の空白を無視する / 空の検索語は全件・元の順
- 既存テストがすべて通る・SwiftLint 警告 0
