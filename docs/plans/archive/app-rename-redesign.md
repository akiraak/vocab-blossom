# アプリ名とデザインを変更する

作成日: 2026-11-07

## 目的・背景

- 2026-11-07 に、アプリを「CEFR デッキからおまかせで出し、覚えた語が花になって庭が育つ」作りから、**グループ中心**（小テストの範囲などをまとめて、学習する・ドリル・穴埋め・読み上げで覚える）に組み替えた → [group-centric-redesign.md](group-centric-redesign.md)
- 名前（vocab-blossom）と見た目（ピンクのアクセント・庭と花の絵・花の絵文字のアイコン）は最初の作りのままなので、今の使い方に合わせて変える

## 決めたこと

| 日付 | 項目 | 決定 |
|---|---|---|
| 2026-11-07 | 新しいアプリ名（#1） | **VocabGarden**（ホーム画面の名前もこの表記。11 文字で省略されない。候補は「Vocab ＋ 植物」の組み合わせから選んだ） |
| 2026-11-07 | デザインの方向（#3） | **スタイリッシュに。でも植物をイメージさせる**（今のやわらかいピンク・絵文字っぽい花から、落ち着いた・洗練された見た目へ） |
| 2026-11-07 | デザインの土台 | **B（ボタニカル・ミニマル）の色味とデザイン ＋ C の区画カード（グループを 2 列のカードにし、達成度に合わせてカードの植物が種 → つぼみ → 花と育つ）**。この組み合わせで 5 パターン（B1〜B5）を作って選ぶ |
| 2026-11-07 | ホームのデザイン | **B4 色面のカード**（白・黒・セージ 1 色、字間の広い「VOCAB GARDEN」、細字の見出し「今日は N 語の復習があります」と丸いバーの「復習する」、グループは枠線の無い薄いセージの色面のカードで、育つほど色が濃くなり、右下に植物の線画を大きく描く） |
| 2026-11-07 | 庭と花の世界観（#4） | 植物のイメージは残す（どこまで残すか・成長の段階の見せ方は Phase 1 の案で決める） |

### デザイン案（2026-11-07、VocabGarden で作り直した版）

- ホーム画面の 3 案とロゴ・アイコン・配色の比較: https://claude.ai/artifact/CkzvtV1jt9JMsHgPCLKQ2Y
  - A 庭の緑: 明るい地に深い緑。ロゴは V の両端が葉になった印 ＋「Vocab**Garden**」。グループを花壇に見立て、グループの語を 1 語ずつ芽・つぼみ・花の線画で地面に並べる
  - B ボタニカル・ミニマル: 白と黒にセージ 1 色。字間を広げた「VOCAB GARDEN」。上に庭の地平線（育った語が花や芽になって並ぶ）を置き、グループは細い線の進み具合
  - C 夜の庭（ダーク）: 黒に近い緑の地に明るい黄緑。グループは 2 列の区画のタイルで、達成度に合わせてタイルの植物が種 → つぼみ → 花と育つ。今日の復習は円のゲージ
  - どの案も、成長の段階（芽・つぼみ・開花）は絵文字をやめて線画にした。ホームの並び・タブ・言葉は今のアプリのまま（「水やり」は A の今日の復習の一言だけ）

### B ＋ 区画カードの 5 パターン（2026-11-07）

- 同じキャンバスの下の段（B1〜B5）
  - B1 地平線＋区画カード: B の庭の地平線と今日の復習の下に、2 列の区画カード（最後は「グループを作る」）
  - B2 大きな数字: 今日の復習の数字を大きく細く。カードの下に細い達成度の線
  - B3 横に流れるカード: 縦長のカードを横にスクロール。下に庭の地平線（開花・つぼみ・芽の数だけ植物が並ぶ）
  - B4 色面のカード: 枠線をやめ、育ち具合で濃さの変わる薄いセージの色面。植物を右下に大きく
  - B5 植物標本のカード: 二重の細い枠・「No. 01」の番号・下に名札のある、植物標本のようなカード

### B4 で描いたほかの画面（2026-11-07）

- 同じキャンバスのいちばん下の段: グループ詳細・学習（4 択）・読み上げ・オンボーディング
  - グループ詳細: 細字のグループ名と数字、薄いセージの色面に「次の学習（復習 N 語 ＋ 新しい単語 N 語）」と「学習する」、ドリル・穴埋め・読み上げの 3 つの色面のボタン、語の一覧（成長の段階の線画・次の復習）
  - 学習（4 択）: 細い進み具合の線と「残り N 問」、形式（EN → JA）と「復習」、色面のカードに大きな細字の単語ともう一度聞くボタン、枠線の選択肢（正解は色面＋チェック）
  - 読み上げ: 色面のカードに単語・品詞と意味（読んでいる文を白で浮かせる）・例文・和訳、ループ・前後・再生のボタン、一覧
  - オンボーディング: ロゴと「覚えたい単語を、自分の庭で育てる。」、種 → つぼみ → 花と色が濃くなる 3 つの手順、最初のグループの名前と「最初のグループを作る」「あとで作る」

### 名前を変える範囲

| 範囲 | 変えるもの | 変えないもの | 注意 |
|---|---|---|---|
| **A: 見える名前だけ（推奨）** | ホーム画面の名前（`CFBundleDisplayName`）・ホームとオンボーディングの見出し・バックアップのファイル名・管理画面の表示名・README と仕様書 | バンドル ID（`com.akiraak.VocabBlossom`）・Xcode のプロジェクト / ターゲット / モジュール名・リポジトリ・サーバー・ドメイン・DB のファイル名 | 端末のデータ（進捗・グループ・音声）はそのまま残る |
| B: A + コードの名前 | A に加えて、Xcode のプロジェクト・ターゲット・モジュール名（`VocabBlossom` → 新しい名前）、`VocabBlossomApp`、テストの `@testable import`、ログの subsystem | バンドル ID・リポジトリ・サーバー | 変更が全ファイルに広がる。バンドル ID は変えないので、データは残る |
| C: すべて | B に加えて、リポジトリ名・手元のディレクトリ・サーバーのコンテナ名と DB のファイル名・g3plus の配置・ドメイン（`vocab.chobi.me`）・project-manager の登録 | — | g3plus-ops・project-manager・CLAUDE.md・メモリの書き換えとデプロイが要る。**バンドル ID を変えると別のアプリとして入り、端末のデータが引き継がれない**（バックアップの書き出し・読み込みで移す） |

## 今の作り（調べた結果）

### 名前が出ているところ

- iOS
  - `ios/project.yml`: `INFOPLIST_KEY_CFBundleDisplayName: vocab-blossom`（ホーム画面の名前）・`name: VocabBlossom`・バンドル ID `com.akiraak.VocabBlossom`
  - 画面: `Features/Home/HomeView.swift`（ナビゲーションの見出し）・`Features/Onboarding/OnboardingView.swift`（大きな見出しと説明「覚えた単語が花になって庭が育つ、英語のことばを増やすアプリ」）
  - バックアップのファイル名: `Core/BackupArchive.swift`（`vocab-blossom-YYYY-MM-DD.json`）
  - ログの subsystem（`com.akiraak.VocabBlossom`。バンドル ID に合わせてあるので、範囲 A・B では変えない）
- サーバー（管理画面）: `server/src/http/html.ts`（`<title>`・左上の名前）・`server/src/main.ts`（起動ログ）・`server/src/config.ts`（DB のファイル名。範囲 C だけ）
- ドキュメント: `README.md`・`docs/specs/app-concept.md`・`docs/specs/deploy-g3plus.md`（範囲 C だけ）・`CLAUDE.md`

### デザイン

- 色: `Core/Theme.swift`（成長の段階の色・正解 / 不正解の色・カードの角丸）、`Assets.xcassets` の `AccentColor`（ピンク、ダークモード用あり）・`LaunchBackground`
- 庭と花の絵: `Features/Home/PlantView.swift`・`GardenView.swift`。使っている画面はホーム・単語の行（`WordRow`）・単語詳細・セッションの締め・統計・オンボーディング
- 背景: `gardenBackground()`（`Theme.swift`）を多くの画面で使っている
- アイコン: `scripts/make-appicon.swift` で 1024px の PNG をコードから書き出して `AppIcon.appiconset` に入れている

## 対応方針

### Phase 1: 名前とデザインの方向を決める

- 上の「決めること」をユーザーと決め、このファイルに書く
- デザインは、決めた方向で色・アイコン・ホームの見た目の案を 2〜3 つ作り（画像か HTML のページ）、見比べて決める

### Phase 2: アプリ名を変える

- 範囲 A なら: 「名前が出ているところ」の iOS の表示名・画面の見出し・オンボーディングの説明・バックアップのファイル名、管理画面の表示名、README・仕様書を直す
  - バックアップのファイル名だけが変わり、中身の形式（版 4）は変えない。前の名前のファイルも今までどおり読み込める（読み込みはファイル名を見ていない）
- 範囲 B・C を選んだら、この Phase を Step に分けて書き足す

### Phase 3: デザインを変える

- 色: `Theme.swift`・`AccentColor`・`LaunchBackground` を新しい色にする（ダークモードの色も決める）
- 庭と花: Phase 1 の決定（#4）に合わせて、`PlantView`・`GardenView`・`GrowthStage` の絵・色・言葉を直す
- アイコン: `scripts/make-appicon.swift` を書き直して書き出す（または用意した画像を入れる）
- 画面ごとに、新しい色で読みにくいところ・浮いているところを直す（ホーム・グループ詳細・セッション・読み上げ・統計・設定・オンボーディング）
- 管理画面: Phase 1 の決定（#6）に合わせる

### Phase 4: 確かめる

- Swift Testing・SwiftLint 警告 0・（管理画面を変えたら）Vitest と型チェック
- シミュレータで DebugSeed を使い、全画面をライト・ダークの両方で撮って見比べる
- 文字とアクセントの色のコントラストが足りているか（白い文字のボタン・薄い背景の上の文字）

### Phase 5: 実機確認

- ホーム画面のアイコンと名前（省略されないか）
- 前の版から更新して、進捗・グループ・マイ単語・読み上げの音声が残っていること
- （管理画面を変えたら）デプロイして本番で表示を確認

## 反映の進め方（2026-11-07、B4 で決まったあと）

未決だった項目は、推奨どおりに進める（ユーザーの「アプリに反映して」を受けて）。

- 名前を変える範囲（#2）: **A（見える名前だけ）**。バンドル ID・プロジェクト名・リポジトリ・サーバー・DB は変えない
- アイコン（#5）: `scripts/make-appicon.swift` を書き直して書き出す（B の図柄: 白地に地平線と、芽・つぼみ・花の線画）。`assets/icon.svg` も同じ図柄にする
- 管理画面（#6）: 名前だけ合わせる（`<title>`・左上の名前・起動ログ）
- 文字: フォントは同梱しない（外部の依存を増やさない）。システムのフォント（英字は SF、和文はヒラギノ）で、細字の見出し・字間の広い英字のロゴを作る
- ダークモード: B4 は明るい画面だけ描いたので、同じ考え方（地は黒に近い緑・セージを明るく）で暗い色を決める

### Step

1. 色と部品: `Theme`（白地・セージ・育ち具合の 4 段階の色面・線の色、ダークの色）、`AccentColor`・`LaunchBackground`、`cardStyle()`（枠線の無い色面・角丸 22）、植物の線画（`PlantView` を線画に。グループのカード用に大きな絵も）、ロゴ（小枝の印 ＋ 字間の広い「VOCAB GARDEN」）。SVG のパスをそのまま使えるよう、小さなパスの読み込みを作る
2. ホーム: B4 の形（細字の見出し「今日は N 語の復習があります」・丸いバーの「復習する」・2 列の色面のカード・「グループを作る」のカード）。グループの削除はカードの長押しメニュー。庭（`GardenView`）はホームから統計の上に移す
   - カードの植物と色面の濃さは、グループの育ち具合（学習を始めていなければ種、達成度 1/3 未満は芽・2/3 未満はつぼみ・それ以上は花）で決める（`GroupStudy.growth`）
3. グループ詳細・学習・読み上げ・オンボーディング: キャンバスの 4 画面に合わせる
4. 残りの画面（統計・設定・単語詳細・締め・穴埋めの準備・単語を追加など）: 新しい色・部品で崩れていないかを見て直す
5. 名前: 表示名 `VocabGarden`・バックアップのファイル名（`VocabGarden-YYYY-MM-DD.json`）・管理画面・README・仕様書・CLAUDE.md
6. アイコンを書き出す
7. 確かめる（Swift Testing・SwiftLint・Vitest・シミュレータでライトとダーク）

## 結果（2026-11-07、Phase 2〜4）

- 名前（範囲 A）: ホーム画面の名前を `VocabGarden` にした。前の `INFOPLIST_KEY_CFBundleDisplayName` は、Info.plist を xcodegen が作るため効いておらず、ホーム画面には `VocabBlossom` と出ていた。`info.properties` の `CFBundleDisplayName` に移して直した。バックアップのファイル名（`VocabGarden-YYYY-MM-DD.json`）・管理画面の `<title>` と左上の名前・起動ログ・README・仕様書・CLAUDE.md も直した
- 色と部品: `Theme` を白地・セージ 1 色・育ち具合の 4 段階の色面にし、ダークの色も決めた（`Color(light:dark:)`）。`AccentColor`（#3F6B4C / ダーク #8DBB98）・`LaunchBackground`（白 / #111513）。カードは枠線の無い色面（角丸 22）、主のボタンは丸いバー（`CapsuleButtonStyle`）。ダークはセージが明るいので、セージの上の文字は暗くした（`Theme.onAccent`）
- 植物の線画: `PlantView` を線画にし、グループのカード用の大きな絵（`PlantIllustration`）とロゴ（`BrandMark`・`BrandWordmark`）を足した。デザインの SVG の座標をそのまま使えるよう `SVGPath`（M・L・H・V・C・Z）を作った
- ホーム: B4 の形にした。グループのカードは育ち具合（`GroupStudy.growth`）で色面と植物が変わる。削除はスワイプからカードの長押しメニューに変えた。庭（`GardenView`）は線画にして統計のいちばん上に移した
- グループ詳細・学習（4 択・新しい単語のカード）・読み上げ・オンボーディング・締め・単語詳細・穴埋めの準備などを、新しい色と部品に合わせた
- アイコン: `scripts/make-appicon.swift` と `assets/icon.svg` を、白地に地平線とつぼみ・花・芽の線画にした（線はホーム画面の大きさで細すぎないよう 2.4）
- 落ちる不具合を 1 つ直した: `Color(light:dark:)` の色を決める処理がメインアクターに縛られ、SwiftUI が描画用のスレッドで色を解決したとき（読み上げ画面など）に落ちていた。処理を `nonisolated` にした
- Swift Testing 309 件すべて通過（`SVGPathTests` 6 件・育ち具合のテストを足した）・SwiftLint 警告 0・Vitest 261 件・型チェック OK
- シミュレータで、ホーム（復習あり・なし）・グループ詳細・学習（4 択）・読み上げ・オンボーディング・統計・設定・単語詳細をライトとダークで撮って確かめた。ホーム画面のアイコンと名前（VocabGarden）も確かめた
  - 見ていないところ: 穴埋め・単語を追加・マイ単語の編集・締めの画面（色と部品を変えただけで、画面では撮っていない）。Phase 5（実機確認）で見る

## 追記: いつも白い画面にする（2026-11-07）

- 実機で「アプリ画面が黒い」との報告。iPhone がダークモードで、ダークの色（地は黒に近い緑）になっていた
- ユーザーと決定: **iPhone がダークモードでも、アプリはいつも白い画面にする**（B4 のデザインどおり）
- Info.plist に `UIUserInterfaceStyle: Light` を入れた（`project.yml` の `info.properties`）。起動画面・シート・システムのアラートも白になる。`Theme` のダークの色は、ダークモードに戻すときのために残した
