# 辞書にない単語（自作語）の登録と出題を改善する

作成日: 2026-11-02

## 目的・背景

グループ機能（[word-groups](word-groups.md)）で自作語を登録できるようになったが、使ってみて次の問題が見つかった。

- **出題の不具合**: 自作語と同梱語の綴りが同じだと、日→英・穴埋めで同じ綴りが 2 つ並び、片方を選ぶと不正解になる
- **誤答肢が簡単すぎる**: 自作語の誤答肢は「全語の同品詞 → 全語」から選んでおり、ほぼ A1〜A2 のやさしい語になる。
  自作語は難しめの語が多いので、消去法で当たってしまう
- **品詞の初期値のまま登録されやすい**: 品詞は「名詞」が初期値で、英語を見て自動推測するのは「空白があれば熟語」だけ。
  動詞なのに名詞のまま登録すると、誤答肢が名詞ばかりになり、穴埋めでは文法だけで答えが分かる。
  また例文に単語が見つからないと穴埋めにならないが、エディタではそれが分からない
- **登録の導線が遠い**: 単語帳から追加で検索して見つからなかったとき、いったん閉じてメニューから「自分で単語を作る」を
  開き、英語を打ち直す必要がある

## 対応方針

### Phase 1: 同じ綴りの語を誤答肢から外す（不具合修正）

- `QuizBuilder.distractors` の候補から、正解と **綴りが同じ語**（前後の空白・大小文字を無視して比較）を外す
- 誤答肢どうしでも綴り・意味が重ならないようにする（同梱データにも同綴りで品詞違いの語があるため）
- 綴りの正規化は `WordStore.bundledWord(spelledLike:)` と共通の関数にまとめる

### Phase 2: 自作語の誤答肢を同じグループの語・ほかの自作語から優先して選ぶ

- `QuizBuilder` に「グループの単語 ID の並び」（`groups: [[String]]`）を渡せるようにする
- 自作語の誤答肢は次の順で **足りない分を埋めていく**（今の「プールに 3 つ以上あればそこから全部」ではなく、
  優先プールから取れるだけ取って、残りを次のプールで埋める）
  1. その語が入っているグループの語 ＋ ほかの自作語（同品詞を先に）
  2. 全語の同品詞
  3. 全語
- 同梱語の誤答肢は従来どおり（同レベル・同品詞 → 同レベル → 全体）
- `SessionView` で `WordGroup` を取得して `SessionRunner` → `QuizBuilder` に渡す。
  毎日の学習に出る自作語の復習でも、所属グループの語から選ばれるようにする

### Phase 3: 自作語エディタで穴埋めにならないことと品詞の見直しを案内する

- 例文が入っていて、`Inflector.findHeadword` で単語が見つからないとき、例文の欄の下に
  「例文に「○○」が見つからないため、穴埋め問題にはなりません」と出す（保存は止めない）
- 品詞をまだ自分で選んでいないとき（自動推測のまま）は、品詞の欄の下に
  「品詞は『名詞』になっています。違うときは選び直してください（選択肢が同じ品詞から選ばれます）」と出す
- 判定はテストできるよう `GroupEditor.WordDraft` 側に置く（例: `canMakeFillBlank`）

### Phase 4: 単語帳から追加で見つからないとき、その場で自作語を作れるようにする

- `WordPickerView` で検索結果が 0 件のとき、空状態に「「○○」を自分で作って追加する」ボタンを出す
- 押すと `CustomWordEditorView` を開き、英語欄に検索語を入れた状態にする（意味の欄にフォーカス）
- 作った語はピッカーの **選択に加える**（`createCustomWord` でグループに直接入れると、
  ピッカーの「完了」で選択外として外されてしまうため）。キャンセルしたらピッカーに戻るだけ
- エディタの「単語帳にあります」案内のボタンも、ピッカーから開いたときはその同梱語を選択に加える
- エディタに `initialWord` と「作った / 選んだ語の ID を返すコールバック」を足す

### 対象外: AI タイポチェック

- TODO の「辞書にない単語を登録するときに AI でタイポチェックを行う」は、このプランから外して別タスクにした
- 方式はユーザー確認済み: **Claude API**。API キーはアプリに埋め込まず、このアプリ用に作る管理画面（Web サーバー）の
  起動時の環境変数（`ANTHROPIC_API_KEY`）に入れ、アプリは管理画面のサーバー経由で判定する
- 管理画面（単語の編集なども行える。g3plus-opt 経由で `xxxx.chobi.me` に配置）を TODO に追加し、その完成後に着手する

## 影響範囲

- Core: `QuizBuilder`、`WordStore`（綴りの正規化）、`GroupEditor`（`WordDraft` の判定）
- Features: `SessionRunner` / `SessionView`（グループを渡す）、`CustomWordEditorView`、`WordPickerView`
- 既存の同梱語の出題（Phase 1 の綴り重複除外は同梱語にも効く）

## テスト方針

- Swift Testing
  - `QuizBuilder`: 同じ綴りの同梱語がある自作語で、選択肢に同じ綴りが 2 つ並ばない（日→英・穴埋め）
  - `QuizBuilder`: 誤答肢どうしの綴り・意味が重ならない（同梱データ全語で確認）
  - `QuizBuilder`: 自作語の誤答肢が同じグループの語・ほかの自作語から優先して選ばれる／足りなければ全体で埋まる
  - `WordDraft`: 例文に単語が無いと穴埋め不可、活用形でも見つかれば可、例文が空なら案内しない
  - `SessionRunner`: グループを渡すと自作語の誤答肢にグループの語が入る
- 既存テストが通ること・SwiftLint 警告 0
- シミュレータで確認: 同綴りの自作語の日→英、エディタの案内、ピッカーからの作成

## Phase

1. 同じ綴りの語を誤答肢から外す
2. 自作語の誤答肢をグループの語・ほかの自作語から優先
3. 自作語エディタの穴埋め・品詞の案内
4. 単語帳から追加で見つからないときに自作語を作るボタン
