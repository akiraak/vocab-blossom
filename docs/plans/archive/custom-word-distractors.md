# 誤答肢に、同じグループに無いマイ単語を出さない

## 目的・背景

穴埋めを実機で試したところ（2026-11-04）、グループから外した commute が、そのグループのほかの問題の選択肢に出てきて不自然だった。

今の `QuizBuilder.distractors` は、マイ単語（自作語）を出題するとき「同じグループの語 ＋ ほかのすべてのマイ単語」から優先して選ぶ
（同梱語は A1〜A2 のやさしい語なので、そこからだけ選ぶと消去法で当たってしまうため）。
グループから外してもマイ単語は残るので、外した語や、ほかのグループのマイ単語も選択肢に出る。
同梱語を出題するときも、最後に埋める「全体」にはマイ単語が入っている。

## 決めたこと（2026-11-04）

- 誤答肢に使うマイ単語は、**出題中の語と同じグループに入っているものだけ**。
  ほかのグループのマイ単語も、どのグループにも入っていないマイ単語も出さない

## 対応方針

- 自作語の誤答肢: 同じグループの語（同品詞 → 全品詞）→ 同梱語の同品詞 → 同梱語の全体
  （`relatedWords` から「ほかの自作語」を外し、残りを埋めるプールを同梱語だけにする）
- 同梱語の誤答肢: 同レベル・同品詞 → 同レベル → 同梱語の全体（最後のプールからマイ単語を外す）
- `WordStore` に同梱語だけの並び（`bundledWords`）を持たせる

## 影響範囲

- iOS: `Core/QuizBuilder.swift`（`distractors`・`relatedWords`）、`Core/WordStore.swift`（`bundledWords`）
- サーバー・同期・データは変えない

## テスト方針

- Swift Testing
  - 自作語の誤答肢は同じグループの語から選び、ほかのグループ・どのグループにも無い自作語は選ばない
  - グループの語が足りなければ同梱語の同品詞で埋め、自作語は入らない
  - 同梱語の誤答肢に自作語が入らない
- 既存テストがすべて通る・SwiftLint 警告 0

## 結果（2026-11-04）

- `WordStore.bundledWords` を足した。自作語の誤答肢は同じグループの語 → 同梱語（同品詞 → 全体）、
  同梱語の誤答肢も最後のプールを同梱語だけにした（`relatedWords` から「ほかの自作語」を外した）
- Swift Testing 218 件成功・SwiftLint 警告 0
