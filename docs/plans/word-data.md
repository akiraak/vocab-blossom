# 単語データ整備プラン

## 目的・背景

[app-concept](../specs/app-concept.md) §5 のとおり、MVP には CEFR A1〜A2 の基本英単語 約 1,200 語 + 基礎熟語 約 200 を JSON で同梱する。
そのための単語リストの出典選定（ライセンス確認）、データスキーマ設計、データ生成を行う。

## 対応方針

- Step 1: 出典候補のライセンス調査（CEFR-J Wordlist / Oxford 3000 / NGSL など）
  - アプリに同梱して配布できること（再配布可）が条件
  - 調査結果と採用判断を `docs/specs/word-data.md` に記録する
- Step 2: データスキーマ設計（デッキ構成・単語エントリの型・置き場所）
  - 型定義を `src/data/types.ts`、デッキ JSON を `src/data/decks/` に置く
- Step 3: データ生成（日本語訳・例文は LLM 生成 + 人手レビュー）
  - デッキ単位で段階的に生成する（A1 前半 → A1 後半 → A2 基礎 → 基礎熟語）
  - 生成データは「未レビュー」扱いとし、人手レビューは別途行う
- Step 4: データ検証テスト（Vitest）
  - 必須フィールド・ID とスペルの重複・レベル値などを機械チェックする

## 影響範囲

- `src/data/` 以下の新規追加、検証テストの追加
- 既存アプリコードへの組み込みは MVP 実装タスクで行う（本タスクはデータまで）

## テスト方針

- デッキ JSON の構造検証テストを Vitest で自動化（全デッキ対象）
- 訳・例文の内容面は人手レビュー（別途、レビュー済みフラグで管理）
