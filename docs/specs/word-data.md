# 単語データ仕様

作成日: 2026-08-13

## 1. 出典とライセンス

### 採用: CEFR-J Wordlist Version 1.6

単語の見出し語・品詞・CEFR レベルは **CEFR-J Wordlist Version 1.6** をベースにする。

- 出典表記（必須）: 『CEFR-J Wordlist Version 1.6』東京外国語大学投野由紀夫研究室
  （URL: http://www.cefr-j.org/download.html より 2026-08-13 ダウンロード）
- 利用条件（[公式サイト](http://www.cefr-j.org/download.html) 2026-08-13 確認）:
  - 適切な引用を行えば**研究教育および商用においても無償で利用できる**
  - **改変して別の語彙表を作ることは可**（本語彙表の適切な引用が必須）
  - 監修などを依頼する場合のみ別途相談・経費
- アプリの「このアプリについて」画面にも上記出典表記を掲載すること（MVP 実装タスクに含める）

### 不採用の候補

- **Oxford 3000/5000**: Oxford University Press の著作物で再配布不可のため不採用
- **NGSL**（CC BY-SA 4.0）: 利用可能だが CEFR レベルが付与されていないため今回は不採用（将来の補完候補）

### このプロジェクトで付加するデータ

日本語の意味・例文・例文訳は本プロジェクトのオリジナル（LLM 生成 + 人手レビュー）。
基礎熟語デッキ（句動詞・慣用表現）は本プロジェクトで独自に選定する。

## 2. 抽出ルール

`scripts/extract-cefrj.py` で xlsx から `data/source/cefrj-a1.tsv` / `cefrj-a2.tsv` を生成する。

- 同一見出し語が複数品詞で載る場合は最初の行（リスト順）のみ採用（アプリでは 1 語 1 エントリ）
  - ただしリスト先頭の品詞が初学者に教える代表品詞として不適切な語（約 50 語）は、スクリプト内の `PRIMARY_POS` で品詞を上書きする（例: catch → verb、ring → noun）。意味・例文もこの品詞に合わせて作成する
- A1 と A2 の両方に載る語は A1 のみに採用
- スラッシュ区切りの表記ゆれ（`a.m./A.M./am/AM`）は先頭の形を採用
- クイズとして成立しない純粋な機能語（冠詞・代名詞・be/do/have の活用形・短縮形など）は除外
- 品詞名は正規化する（`modal auxiliary` → `modal`、`be-verb/do-verb/have-verb` → `verb`）

抽出結果: A1 = 1,012 語、A2 = 1,231 語（2026-08-13 時点）

## 3. データスキーマ

型定義は `src/data/types.ts`、デッキ JSON は `data/decks/*.json`。

```jsonc
// Deck
{
  "id": "a1-1",
  "name": "A1 前半",
  "words": [
    // WordEntry
    {
      "id": "a1-0001",        // レベル別の連番。進捗保存のキーになるため不変
      "word": "a.m.",
      "pos": "adverb",         // noun | verb | adjective | adverb | preposition | conjunction
                               // | interjection | number | determiner | pronoun | modal | phrase
      "level": "A1",           // A1 | A2（熟語デッキはエントリごとに付与）
      "meaning": "午前",       // 初学者向けに 1〜2 個まで。複数は「／」区切り
      "example": "I get up at 7 a.m.",
      "exampleJa": "私は午前7時に起きます。"
    }
  ]
}
```

## 4. デッキ構成

| デッキ ID | 名前 | 内容 | 語数 |
|---|---|---|---|
| a1-1 | A1 前半 | cefrj-a1.tsv の 1〜506 行目 | 506 |
| a1-2 | A1 後半 | 同 507〜1012 行目 | 506 |
| a2-1 | A2 前半 | cefrj-a2.tsv の 1〜616 行目 | 616 |
| a2-2 | A2 後半 | 同 617〜1231 行目 | 615 |
| phrases | 基礎熟語 | 句動詞・慣用表現（独自選定） | 200 |

- ID は TSV の行順（アルファベット順）に連番を振る。**一度公開した ID は変更しない**（学習進捗のキーのため）
- 4択の誤答肢は「同レベル・同品詞」から選ぶが、母数が 4 未満の品詞（interjection など）は同レベル全体にフォールバックする（MVP 実装側の仕様）

## 5. 生成と品質管理

- 意味・例文・例文訳は LLM 生成。例文は A1 文法レベルの短文（3〜12 語、平均約 6 語）とし、見出し語を必ず含める
- 構造検証は `src/data/decks.test.ts` で自動化する

### 5.1 自動チェック（`src/data/decks.test.ts`）

| チェック | 内容 |
|---|---|
| 必須フィールド・形式 | 空文字なし、ID 形式、品詞・レベルの値 |
| ID / 単語の一意性 | 全デッキ横断 |
| 抽出元 TSV との一致 | A1/A2 の語・品詞・レベル・順序・連番 |
| **`meaning` の一意性** | 全デッキ横断。同じ訳の語が 2 つあると 4 択で正解が複数になるため |
| **`example` の一意性** | 全デッキ横断。同じ例文だと穴埋めの答えが一意に定まらないため |
| **例文が見出し語を含む** | 活用形を許容（`src/lib/inflect.ts`） |
| 例文の語数 | 3〜12 語 |
| `meaning` の個数 | 「／」1 個まで（意味は 2 つまで） |
| `exampleJa` の文末 | 「。」「？」「！」のいずれか |

見出し語の照合は規則変化（複数形・三単現・過去形・-ing・比較級・-ly）+ 不規則変化表で行う。
熟語は先頭語・末尾語の活用、冠詞の省略（`make a mistake` → `makes mistakes`）、
句動詞への目的語の割り込み（`call back` → `call you back`）を許容する。
このロジックは MVP の穴埋めクイズ（例文中の該当語を空欄化する）でも使う。

### 5.2 内容レビュー（2026-08-14 実施）

内容面（訳・例文の正しさ）は、**生成時とは独立したレビュー観点を与えた LLM の第 2 パス**で全 2,443 件を
点検した（人手による全件レビューは非現実的なため、機械チェック + 第 2 パス + 人手スポットチェックの
3 層で担保する方針）。判断基準は「明確な誤りだけを直す。迷ったら変更しない」。

修正結果: **137 エントリ**（`meaning` 93 / `example` 42 / `exampleJa` 41）。
`id` / `word` / `pos` / `level` は変更していない。

| 種別 | 件数 | 例 |
|---|---|---|
| 誤った語法・コロケーション | 32 エントリ | `This beef is very soft.` → `tender` が正しい／`live in this mountain` → `on`／`feel envy at` は語法誤り／ゾウの鼻は `nose` ではなく `trunk` |
| 品詞と意味・例文の不一致 | 同上に含む | `excuse`(noun) に動詞用法 `Excuse me` の例文／`fun`(adj) に名詞用法の例文／`kindly`(adj) に副詞の訳 |
| 見出し語の意味が伝わらない例文 | 同上に含む | `course` に `of course`／`hall` に `city hall`（訳も「市民ホール」と誤訳）／`flea` に `flea market` |
| 不適切な題材 | 2 エントリ | 喫煙・飲酒の場面を中立な文脈に差し替え |
| **重複の解消** | 105 エントリ | `meaning` 79 グループ（161 語）、`example` 17 グループ（36 語） |

重複解消では、同義語を訳語のニュアンスや語法注記で書き分けた
（例: excellent「優秀な／非常に優れた」/ wonderful「すばらしい」、bike「自転車（bicycle のくだけた言い方）」）。
この注記は、日→英 4 択で同義語が選択肢に並んだときに問題を成立させる役割も持つ。

レビュー提案の適用には `scripts/apply-review.py` を使う（`meaning` / `example` / `exampleJa` のみ更新し、
現在値が提案の `old` と一致しないものはスキップする）。

### 5.3 既知の制約

- **品詞タグと例文の用法がずれる語がある**（`about` / `above` / `past` / `still` / `latter` など）。
  CEFR-J のリスト先頭の品詞をそのまま採用しているため（§2）で、`pos` は抽出元 TSV と一致させる
  テストで固定されている。訳・例文は初学者にとって自然な用法で書いてあるため、現状は許容する
- レビューは LLM による第 2 パスであり、人手による全件確認は行っていない。
  スポットチェックで誤りが見つかった場合は `scripts/apply-review.py` の形式で修正を適用する
