# vocab-blossom アプリコンセプト

作成日: 2026-08-13
改定: 2026-11-07（グループ中心の作りに変更・読み上げをすべて Gemini の声に変更 → [plan](../plans/archive/group-centric-redesign.md)）

## 1. 一言でいうと

**覚えた単語が花になって庭が育つ、英語初学者向けの単語学習 iOS アプリ。**

間隔反復（SRS）で「忘れる前に復習する」仕組みを、初学者に難しさを感じさせない形で提供する。学習の進み具合は「種 → 芽 → つぼみ → 開花」という花の成長で可視化し、続けるほど自分の庭が華やかになっていく。

## 2. ターゲットと利用シーン

- **ターゲット**: 英語初学者（CEFR A1〜A2。日本の学校教育でいう中学〜高校基礎レベル）
  - Anki のような高機能ツールは設定が難しくて挫折する層
  - 単語帳（紙）は続かなかった層
  - 小テストの範囲・教科書の単元など、**自分で覚えたい語のまとまりがある人**（2026-11-07 からこちらを中心にした）
- **利用シーン**:
  - **iPhone**: 通勤・すき間時間に 1〜3 分のクイズをこなす（メインの学習動線）
  - **PC**（将来）: 自宅でまとまった学習、単語一覧の閲覧、スペル入力練習など
- **前提**: MVP は iPhone 単独で完結させる（→ §8-5）。PC 対応を入れる段階で学習進捗の同期が必要になる（→ §8-1）

## 3. コア体験

### 3.1 学習ループと 1 セッションの流れ

> **2026-11-07 改定**: 当初は「CEFR デッキから毎日おまかせで新規語を出す」1 本道だったが、実際にはグループで学ぶ使い方が中心になったため、
> **グループを軸にした学習**に組み替えた。おまかせの新規語・学習レベルの設定・既知語の一括登録はやめた。

学習の単位は**グループ**（ユーザーが作る単語・フレーズのまとまり。→ §5）。ホームからグループを選び、次のどれかで学ぶ。

1. **学習する（SRS）**: グループ内の「期限が来た復習」と「まだ学習していない語」を出す
   - 新しい単語はグループの追加順に **1 回 10 語**まで。5 語ずつのミニバッチで「提示 → 直後クイズ」を繰り返す
   - **提示カード**: 単語・発音（自動再生）・意味・品詞・例文。「**もう知ってる**」ボタンを置き、押された単語は**開花扱い**（次回は約 3 ヶ月後の維持復習のみ）にする
   - **直後クイズ**: 提示した 5 語を 4 択で確認。正解して初めて「芽」になる
   - 範囲を覚え切る用途なので、その日にすでに学習した数では絞らない（上限まで出し切ったら、もう一度開けば続きが出る）
2. **ドリル**: グループの全語を一周するクイズ。進捗・SRS は動かさない（練習用）
3. **穴埋め**: AI（Claude）が作った 2〜3 文の文章の空欄に入る語を選ぶドリル。文章は始めるときに無い語の分だけ作り、端末にためておく
4. **読み上げ**: グループの語を「単語 → 意味 → 例文 → 例文の和訳」の順に続けて読む。ループ再生・ロック中の再生ができる

ほかに、ホームの**今日の復習**で、期限が来た語をグループをまたいでまとめて復習できる（グループに入っていない、前の版で学習を始めた語も出す）。今日の復習には新しい単語は出さない。

どのセッションも、回答するたびに正誤 + 単語カード（意味・例文・音声自動再生）を表示し、最後に締めの画面（今日成長した単語・咲いた花）を出す。グループで答えた記録は、グループ一覧の回答数・達成度（最後の回答が正解だった語の割合）に出す。

### 3.2 blossom（花）の世界観

単語の定着度を花の成長で表す。

| 定着度 | 状態 | 意味 |
|---|---|---|
| 0 | 種 | 未学習 |
| 1〜2 | 芽 | 学習を始めたばかり |
| 3〜4 | つぼみ | 復習を重ねている |
| 5 | 開花 | 定着（長期間隔の復習のみ） |

ホーム画面のいちばん下に「庭」を置く。覚えた単語の数だけ花が咲き、連続学習日数（ストリーク）などと合わせて継続のモチベーションにする。数値やグラフより先に「庭が育つ」絵で進捗を感じられるようにする（2026-11-07 から、毎日見るのは今日の復習とグループなので、庭はホームの下に置いた）。

### 3.3 SRS（間隔反復）は単純に

初学者向けなので、FSRS / SM-2 のような複雑なアルゴリズムではなく、**段階固定の Leitner 方式**にする。

- 正解するとステージが 1 つ上がり、次回復習日が延びる: 1日 → 3日 → 1週間 → 2週間 → 1ヶ月。最終復習に正解で「開花」、以後は約 3 ヶ月ごとの維持復習のみ
- 間違えるとステージが 1 つ下がり（最低は芽まで）、そのセッションの最後にもう一度出題する。正解するまでセッションは終わらない（ただし同一カードの再出題は 2 回まで）
- ユーザーには「次はいつ復習」だけ見せ、アルゴリズムは見せない

**挫折させないための調整弁:**

- **復習の 1 日上限**: サボって復習が溜まっても圧殺されないよう、期限超過の古い順に上限まで選び、残りは翌日に繰り越す（選んだあとの出題順はシャッフルする）
- **新規語の自動調整**: 復習残が上限を超えているときは新規語を出さない
- **上限は設定項目にせず、固定値にする**（2026-11-07〜。新規語 1 回 10 語・復習 1 日 60 語。`StudyLimits`）
  1 語は開花までに 5 回戻ってくるので、定常状態の復習数は新規語 × 5 になる。復習の上限をその 6 倍にして、
  上の抑制ルールで新規語が出なくなる事故を防ぐ（以前は「1 日の新規語数」を設定でき、復習上限を `max(60, 新規語 × 6)` で決めていた）

## 4. 出題形式

単語単体だけでなく、**文章（例文）と音声でも同じ単語を繰り返し問う**。ステージが上がるごとに「見て分かる → 文脈で分かる → 思い出せる → 聞いて分かる」と深い形式に進み、1 つの単語が成長の過程で全形式を経験する。形式はステージからアプリが自動で選び、ユーザーは選ばない。

| ステージ | 種類 | 形式 | 問い方 | 対象 |
|---|---|---|---|---|
| 芽（1〜2） | 単語単体 | 英→日 4択 | 英単語を見て日本語の意味を選ぶ（音声も自動再生） | MVP |
| つぼみ（3） | 文章 | 例文穴埋め 4択 | 対象語が空欄になった例文を読み、入る単語を選ぶ | MVP |
| つぼみ（4） | 単語単体 | 日→英 4択 | 日本語の意味から英単語を選ぶ | MVP |
| 開花前・維持（5〜） | 音声 | リスニング 4択 | 音声（単語 + 例文、TTS）だけを聞いて意味を選ぶ | MVP |
| —（PC 向け） | 文章 | スペル入力 | 意味・例文を見て英単語をタイプする | 将来 |

- すべての単語に**例文 1 つ以上**と**音声**を付ける
- **音声は Gemini の TTS**（2026-11-07〜。サーバー経由で作る。声は Chobi / Naruko の 2 人）。提示カード・出題時・回答後・リスニング・スピーカーのボタン・グループの読み上げのすべてで同じ声を使う
  - 学習中は読む人を語ごとに固定し、セッションのこの先の語を先読みして待ち時間をなくす。音声は端末に残して使い回す
  - 音声が取れない文（オフライン・サーバーの失敗・サーバーの設定なし）は、OS 内蔵の声（`AVSpeechSynthesizer`）で読む。学習中は、音声を待つのは 3 秒までで、過ぎた文も内蔵の声で読む
- クイズだけでなく、提示カード・回答後カードでも音声を自動再生し、常に「目 + 耳」のセットで触れさせる
- 4択の誤答肢は同レベル・同品詞の単語からランダム生成する（紛らわしすぎる選択肢で初学者を折らない）。マイ単語は同じグループの語も使う
- 正誤にかかわらず、回答後に「単語・意味・例文・音声」をまとめて表示して定着を促す
- 回答した瞬間に正誤の効果音（正解はチャイム、不正解は低いブザー）を鳴らし、画面を見ていなくても結果が分かるようにする。効果音は同梱アセットではなくコードで波形を合成する（設定でオフにできる）

## 5. 収録コンテンツ

- **MVP**: A1〜A2 の基本英単語 約 1,200 語 + 基礎熟語 約 200（CEFR レベル別デッキに分割: A1 前半 / A1 後半 / A2 基礎 / 基礎熟語 など)
- データはアプリに JSON で同梱する（`word, 意味, 品詞, 例文, 例文訳, レベル(CEFR)`）。2026-11-07 からは、グループの「単語を追加」で探す語・4 択の誤答肢として使う
- 単語リストは CEFR レベルつきの公開リスト（CEFR-J Wordlist、Oxford 3000 など）をベースに、日本語訳・例文を整備する（整備方法・ライセンス確認は別タスク）
- ~~**学習レベルはユーザーが設定する**~~（2026-11-07 にやめた。新規語はグループから出すので、レベルの設定は使わない。前の版の値はバックアップの形式を変えないためだけに残している）
- **グループ（マイ単語帳）**: ユーザーがグループを作り、同梱語を選ぶ・自分で単語/フレーズを作る（自作語＝マイ単語）ことで登録できる。登録の入口は「単語を追加」の 1 つで、検索して単語帳（同梱語 + マイ単語）にあれば選び、無ければその場で AI で調べて（使えなければ自分で入力して）作る。どちらも同じ画面で選び、「追加」1 回で確定する。マイ単語は意味ごとに品詞・例文を持て（複数の品詞）、同じ綴りのマイ単語は 1 つだけにする（作り直すと内容を置き換える）。管理画面（Web）のグループ詳細も同じ流れ → [plan](../plans/archive/unified-word-add.md)。グループ単位で「学習する（SRS 共有。進捗は単語ごとに共通で庭・今日の復習にも反映）」「ドリル（全語を一周。進捗・ログを動かさない）」「穴埋め」「読み上げ」ができる（→ §3.1） → [plan](../plans/archive/word-groups.md)。グループとマイ単語は管理画面のサーバーと同期する
- 将来: B1（中級手前）レベル

## 6. 画面構成

> 2026-11-07 にグループ中心に組み替えた。下部タブは「**ホーム / 統計 / 設定**」の 3 つ（以前は ホーム / 単語帳 / グループ / 統計 / 設定）。

1. **初回オンボーディング**: 使い方の短い説明（グループを作る → グループで学習する → 庭が育つ）と、最初のグループの名前を入れて「最初のグループを作る」。「あとで作る」で飛ばせる
2. **ホーム**: 上から順に
   - **今日の復習**: 期限が来た語をまとめて復習するボタン（グループをまたぐ。新しい単語は出さない）。ストリークと今日の回答数
   - **グループ**: グループごとの語数・学習済み・復習の数・回答数・達成度。右上の ＋ で作る・スワイプで削除・引っ張って同期
   - **庭**: 咲いた花と成長の内訳
3. **グループ詳細**: 学習する・ドリル・穴埋め・読み上げのボタンと、グループの語の一覧。「単語を追加」（検索して選ぶ・無ければ AI で調べて作る）・外す・名前の変更
4. **学習/復習画面**: クイズ形式で 1 問ずつ出題、回答後に単語詳細を表示（フルスクリーン）
5. **単語詳細**: 意味・例文・音声・成長状態・復習履歴・入っているグループ。マイ単語は編集・削除もここ
6. **統計**: 学習した語数、正答率、日別の学習量
7. **設定**: 読み上げのオン/オフ、正解・不正解の効果音のオン/オフ、**マイ単語**（自分で作った単語の一覧）、進捗のエクスポート/インポート、サーバーとの同期、AI のモデル（サーバーがあるとき）

iPhone の縦画面を基準にデザインする（下部タブ + セッションはフルスクリーン）。iPad / PC 向けのレイアウトは将来対応。

## 7. 技術方針（2026-08-14 改定）

> **改定履歴**: 当初は「レスポンシブ Web アプリ（PWA）+ 将来 iOS アプリ化」を採用していたが、
> 2026-08-14 に **MVP から iOS ネイティブで作る**方針へ変更した（→ §8-5）。
> 旧方針は [ios-native-migration プラン](../plans/archive/ios-native-migration.md) に経緯を残している。

- **形態**: iOS ネイティブアプリ（iPhone 専用、縦向き）。PC 対応は当面あきらめ、iPhone のすき間学習に集中する
- **フロントエンド**: SwiftUI + Observation（Deployment Target: iOS 18.0）
- **データ保存（MVP）**: ローカルファースト。SwiftData に学習進捗を保存し、バックエンドなしで動かす。設定は `UserDefaults`
  - 2026-11 からは、グループとマイ単語を管理画面のサーバー（`server/`）と同期する。学習の記録は端末の中だけに残す。サーバーの設定が無ければ端末の中だけで動く
- **単語データ**: JSON をアプリバンドルに同梱（整備は従来どおり Python / Node のスクリプトで行う）
- **音声**: Gemini の TTS をサーバー経由で使う（2026-11-07〜。→ §4）。取れないときは `AVSpeechSynthesizer`（OS 内蔵 TTS）
- **AI**: マイ単語の下書き（意味・例文）・穴埋めの文章づくりに Claude をサーバー経由で使う
- **配信**: MVP は開発者ビルドで自分の端末へ。App Store 配信は将来検討
- **将来**: アカウント + 同期用の軽量バックエンド（→ §8-1）、PC / iPad 対応

外部ライブラリへの依存は追加しない。

## 8. 決定事項（2026-08-13 確定）

いずれも推奨案どおりに決定。前提が変われば見直す。

1. **端末間の進捗同期**: MVP はローカル保存 + 進捗のエクスポート/インポート（JSON）。アカウント同期は複数端末で使うようになった時点で導入する（§8-5 により iPhone 単独運用となり、優先度が下がった）
2. **単語データの整備方法**: CEFR レベルつき公開リストをベースに、日本語訳・例文は LLM 生成 + 人手レビューで整備する
3. **1 日の新規語数のデフォルト**: 10 語（設定で 5 / 10 / 15 / 20 / 30 / 50 / 100 から選べる）
   - 2026-11-07 改定: 設定項目をやめ、グループの「学習する」1 回の新規語を 10 語に固定した（→ §3.3）
4. **収録レベルの範囲**: MVP は A1〜A2 まで（B1 は将来）
5. **実装形態（2026-08-14 追加・§7 を改定）**: MVP から **iOS ネイティブ（SwiftUI）** で実装する。Web/PWA 版の実装は中止する
   - これに伴い §2 の「iPhone と PC の両方」は **iPhone 優先**に見直す。PC 対応は将来課題
   - 単語データ・SRS 仕様・出題形式・画面構成の設計判断は Web 版からそのまま引き継ぐ

## 9. MVP スコープまとめ

- CEFR レベル別デッキ（A1〜A2 の基本英単語 + 基礎熟語、同梱 JSON）
- 学習レベルのユーザー設定（初回オンボーディングで選択、設定でいつでも変更可）
- 今日の学習（新規 N 語、提示 → 直後クイズ、「もう知ってる」ボタン）+ SRS 復習（Leitner 方式、1 日上限つき）
- 出題: 英→日 / 日→英 4択、例文穴埋め 4択、リスニング 4択（ステージ連動でアプリが自動選択）
- 庭（開花ビジュアル）+ ストリーク
- 単語帳一覧・統計・設定
- iOS ネイティブ（iPhone 専用）/ ローカル保存（同期なし、エクスポート/インポートのみ）

上は MVP の当時のまとめ。2026-11-07 時点の機能は次のとおり。

- グループ（作る・単語を追加・外す）とマイ単語（AI の下書きつきで作る・複数の品詞）。管理画面のサーバーと同期
- グループの学習する（SRS）・ドリル・穴埋め（AI の文章）・読み上げ、回答数と達成度
- ホームの今日の復習（グループをまたぐ）+ 庭（開花ビジュアル）+ ストリーク
- 出題: 英→日 / 日→英 4択、例文穴埋め 4択、リスニング 4択（ステージ連動でアプリが自動選択）
- 読み上げはすべて Gemini の TTS（取れないときは内蔵の声）
- 統計・設定（マイ単語・エクスポート/インポート・同期・AI のモデル）
- 学習レベルの設定・毎日のおまかせの新規語・単語帳タブ・既知語の一括登録はやめた
