# vocab-blossom アプリコンセプト

作成日: 2026-08-13

## 1. 一言でいうと

**覚えた単語が花になって庭が育つ、英語初学者向けの単語学習 iOS アプリ。**

間隔反復（SRS）で「忘れる前に復習する」仕組みを、初学者に難しさを感じさせない形で提供する。学習の進み具合は「種 → 芽 → つぼみ → 開花」という花の成長で可視化し、続けるほど自分の庭が華やかになっていく。

## 2. ターゲットと利用シーン

- **ターゲット**: 英語初学者（CEFR A1〜A2。日本の学校教育でいう中学〜高校基礎レベル）
  - Anki のような高機能ツールは設定が難しくて挫折する層
  - 単語帳（紙）は続かなかった層
- **利用シーン**:
  - **iPhone**: 通勤・すき間時間に 1〜3 分のクイズをこなす（メインの学習動線）
  - **PC**（将来）: 自宅でまとまった学習、単語一覧の閲覧、スペル入力練習など
- **前提**: MVP は iPhone 単独で完結させる（→ §8-5）。PC 対応を入れる段階で学習進捗の同期が必要になる（→ §8-1）

## 3. コア体験

### 3.1 学習ループと 1 セッションの流れ

1 セッションは「**復習 → 新規学習 → 締めの庭**」の一本道（1 日 5〜10 分想定）。ユーザーは何を勉強するか・どの形式で解くかを一切選ばず、「ボタンを押す → クイズに答える」だけ。

1. **復習（先にやる）**: SRS の期限が来た単語を 1 問ずつクイズ。回答するたびに正誤 + 単語カード（意味・例文・音声自動再生）を表示する
2. **新規学習**: 設定した学習レベル（CEFR）のデッキから 1 日 N 語（デフォルト 10 語、変更可）。5 語ずつのミニバッチで「提示 → 直後クイズ」を繰り返す
   - **出す順番はシャッフルする**: デッキは ABC 順（＝ ID 順）なので、そのままだと毎日 a から順に進んでしまう。単語 ID と端末ごとの種から並びを決めることで、「ABC 順にならない」と「同じ端末なら毎回同じ並び（中断して開き直しても残りの語が入れ替わらない）」を両立させる。熟語も全体に散る
   - **提示カード**: 単語・発音（自動再生）・意味・品詞・例文。「**もう知ってる**」ボタンを置き、押された単語は**開花扱い**（次回は約 3 ヶ月後の維持復習のみ）にして既知語を早く畑から片付ける
   - 既知語は初回オンボーディングと設定から**まとめて登録**できる（未学習語をグリッドで並べ、60 語ずつタップで選ぶ）
   - **直後クイズ**: 提示した 5 語を 4 択で確認。正解して初めて「芽」になる
3. **締め**: 今日成長した単語・咲いた花・ストリーク更新を庭の画面で見せて終了

### 3.2 blossom（花）の世界観

単語の定着度を花の成長で表す。

| 定着度 | 状態 | 意味 |
|---|---|---|
| 0 | 種 | 未学習 |
| 1〜2 | 芽 | 学習を始めたばかり |
| 3〜4 | つぼみ | 復習を重ねている |
| 5 | 開花 | 定着（長期間隔の復習のみ） |

ホーム画面は「庭」。覚えた単語の数だけ花が咲き、連続学習日数（ストリーク）などと合わせて継続のモチベーションにする。数値やグラフより先に「庭が育つ」絵で進捗を感じられるようにする。

### 3.3 SRS（間隔反復）は単純に

初学者向けなので、FSRS / SM-2 のような複雑なアルゴリズムではなく、**段階固定の Leitner 方式**にする。

- 正解するとステージが 1 つ上がり、次回復習日が延びる: 1日 → 3日 → 1週間 → 2週間 → 1ヶ月。最終復習に正解で「開花」、以後は約 3 ヶ月ごとの維持復習のみ
- 間違えるとステージが 1 つ下がり（最低は芽まで）、そのセッションの最後にもう一度出題する。正解するまでセッションは終わらない（ただし同一カードの再出題は 2 回まで）
- ユーザーには「次はいつ復習」だけ見せ、アルゴリズムは見せない

**挫折させないための調整弁:**

- **復習の 1 日上限**: サボって復習が溜まっても圧殺されないよう、期限超過の古い順に上限まで選び、残りは翌日に繰り越す（選んだあとの出題順はシャッフルする）
- **新規語の自動調整**: 復習残が上限を超えている日は新規語を出さない
- **復習上限は設定項目にせず、新規語数から自動で決める**（`max(60, 新規語/日 × 6)`）
  1 語は開花までに 5 回戻ってくるので、定常状態の復習数は新規語 × 5 になる。
  2 つを別々に設定できるようにすると「復習上限 < 新規語 × 5」に設定してしまい、
  上の抑制ルールで新規語が永久に出なくなる事故が起きるため

## 4. 出題形式

単語単体だけでなく、**文章（例文）と音声でも同じ単語を繰り返し問う**。ステージが上がるごとに「見て分かる → 文脈で分かる → 思い出せる → 聞いて分かる」と深い形式に進み、1 つの単語が成長の過程で全形式を経験する。形式はステージからアプリが自動で選び、ユーザーは選ばない。

| ステージ | 種類 | 形式 | 問い方 | 対象 |
|---|---|---|---|---|
| 芽（1〜2） | 単語単体 | 英→日 4択 | 英単語を見て日本語の意味を選ぶ（音声も自動再生） | MVP |
| つぼみ（3） | 文章 | 例文穴埋め 4択 | 対象語が空欄になった例文を読み、入る単語を選ぶ | MVP |
| つぼみ（4） | 単語単体 | 日→英 4択 | 日本語の意味から英単語を選ぶ | MVP |
| 開花前・維持（5〜） | 音声 | リスニング 4択 | 音声（単語 + 例文、TTS）だけを聞いて意味を選ぶ | MVP |
| —（PC 向け） | 文章 | スペル入力 | 意味・例文を見て英単語をタイプする | 将来 |

- すべての単語に**例文 1 つ以上**と**音声（OS 内蔵 TTS: `AVSpeechSynthesizer`）**を付ける
- クイズだけでなく、提示カード・回答後カードでも音声を自動再生し、常に「目 + 耳」のセットで触れさせる
- 4択の誤答肢は同レベル・同品詞の単語からランダム生成する（紛らわしすぎる選択肢で初学者を折らない）
- 正誤にかかわらず、回答後に「単語・意味・例文・音声」をまとめて表示して定着を促す
- 回答した瞬間に正誤の効果音（正解はチャイム、不正解は低いブザー）を鳴らし、画面を見ていなくても結果が分かるようにする。効果音は同梱アセットではなくコードで波形を合成する（設定でオフにできる）

## 5. 収録コンテンツ

- **MVP**: A1〜A2 の基本英単語 約 1,200 語 + 基礎熟語 約 200（CEFR レベル別デッキに分割: A1 前半 / A1 後半 / A2 基礎 / 基礎熟語 など)
- データはアプリに JSON で同梱する（`word, 意味, 品詞, 例文, 例文訳, レベル(CEFR)`）
- 単語リストは CEFR レベルつきの公開リスト（CEFR-J Wordlist、Oxford 3000 など）をベースに、日本語訳・例文を整備する（整備方法・ライセンス確認は別タスク）
- **学習レベルはユーザーが設定する**: 初回起動時に CEFR レベル（A1 / A2）を選び、新規語は選択中レベルのデッキから出題する。レベルは設定でいつでも変更でき、変更しても学習済みの進捗・復習スケジュールは保持される
- 将来: B1（中級手前）レベル、ユーザー自身の単語登録（マイ単語帳）

## 6. 画面構成（案）

1. **初回オンボーディング**: 学習レベル（A1 / A2）を選んでから学習を開始する（将来: 数問のミニクイズでレベルを推定して提案）
2. **ホーム（庭）**: 咲いた花の数、ストリーク、「今日の学習」ボタン（復習と新規学習は 1 本の導線に統合した）
3. **学習/復習画面**: クイズ形式で 1 問ずつ出題、回答後に単語詳細を表示
4. **単語帳一覧**: デッキ別の単語リスト、各単語の成長状態、検索
5. **単語詳細**: 意味・例文・音声・復習履歴
6. **統計**: 学習した語数、正答率、日別の学習量
7. **設定**: 学習レベル（いつでも変更可）、1 日の新規語数（5〜100）、読み上げのオン/オフ、正解・不正解の効果音のオン/オフ、知っている単語の一括登録、進捗のエクスポート/インポート

iPhone の縦画面を基準にデザインする（下部タブ + セッションはフルスクリーン）。iPad / PC 向けのレイアウトは将来対応。

## 7. 技術方針（2026-08-14 改定）

> **改定履歴**: 当初は「レスポンシブ Web アプリ（PWA）+ 将来 iOS アプリ化」を採用していたが、
> 2026-08-14 に **MVP から iOS ネイティブで作る**方針へ変更した（→ §8-5）。
> 旧方針は [ios-native-migration プラン](../plans/archive/ios-native-migration.md) に経緯を残している。

- **形態**: iOS ネイティブアプリ（iPhone 専用、縦向き）。PC 対応は当面あきらめ、iPhone のすき間学習に集中する
- **フロントエンド**: SwiftUI + Observation（Deployment Target: iOS 18.0）
- **データ保存（MVP）**: ローカルファースト。SwiftData に学習進捗を保存し、バックエンドなしで動かす。設定は `UserDefaults`
- **単語データ**: JSON をアプリバンドルに同梱（整備は従来どおり Python / Node のスクリプトで行う）
- **音声**: `AVSpeechSynthesizer`（OS 内蔵 TTS、追加コストなし）
- **配信**: MVP は開発者ビルドで自分の端末へ。App Store 配信は将来検討
- **将来**: アカウント + 同期用の軽量バックエンド（→ §8-1）、PC / iPad 対応

外部ライブラリへの依存は追加しない。

## 8. 決定事項（2026-08-13 確定）

いずれも推奨案どおりに決定。前提が変われば見直す。

1. **端末間の進捗同期**: MVP はローカル保存 + 進捗のエクスポート/インポート（JSON）。アカウント同期は複数端末で使うようになった時点で導入する（§8-5 により iPhone 単独運用となり、優先度が下がった）
2. **単語データの整備方法**: CEFR レベルつき公開リストをベースに、日本語訳・例文は LLM 生成 + 人手レビューで整備する
3. **1 日の新規語数のデフォルト**: 10 語（設定で 5 / 10 / 15 / 20 / 30 / 50 / 100 から選べる）
4. **収録レベルの範囲**: MVP は A1〜A2 まで（B1 は将来）
5. **実装形態（2026-08-14 追加・§7 を改定）**: MVP から **iOS ネイティブ（SwiftUI）** で実装する。Web/PWA 版の実装は中止する
   - これに伴い §2 の「iPhone と PC の両方」は **iPhone 優先**に見直す。PC 対応は将来課題
   - 単語データ・SRS 仕様・出題形式・画面構成の設計判断は Web 版からそのまま引き継ぐ

## 9. MVP スコープまとめ

- CEFR レベル別デッキ（A1〜A2 の基本英単語 + 基礎熟語、同梱 JSON）
- 学習レベルのユーザー設定（初回オンボーディングで選択、設定でいつでも変更可）
- 今日の学習（新規 N 語、提示 → 直後クイズ、「もう知ってる」ボタン）+ SRS 復習（Leitner 方式、1 日上限つき）
- 出題: 英→日 / 日→英 4択、例文穴埋め 4択、リスニング 4択（ステージ連動でアプリが自動選択）
- 庭（開花ビジュアル）+ ストリーク
- 単語帳一覧・統計・設定
- iOS ネイティブ（iPhone 専用）/ ローカル保存（同期なし、エクスポート/インポートのみ）
